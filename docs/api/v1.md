# 99staples API v1

JSON API for the Godot game client, under `/api/v1`. The contract is machine-checked:

- **Shapes:** JSON Schemas in [`spec/support/schemas/`](../../spec/support/schemas/), enforced against every
  endpoint by `spec/requests/api/v1/schemas_spec.rb`. Field-level notes live in each schema's `description`.
- **Examples:** real responses from `bin/rails "api:export_fixtures[<deck ids>,<precon id>]"`, written to
  `tmp/api_fixtures/` (with a copy of the schemas) and copied into the game repo at `tests/fixtures/api/`.

This page covers only what the schemas can't express. Change a response, its schema and this page together.

## Endpoints

| Endpoint | Response | Notes |
| --- | --- | --- |
| `GET /health` | [health](../../spec/support/schemas/health.json) | No auth. Called on boot. |
| `POST /sessions` | [session](../../spec/support/schemas/session.json) (201) | No auth. `email`, `password`, optional `device_name`. |
| `DELETE /sessions` | 204, no body | Revokes this token only. |
| `GET /me` | [user](../../spec/support/schemas/user.json) | Includes `preferences`. |
| `GET /decks` | page of [deck_summary](../../spec/support/schemas/deck_summary.json) | Your decks, public and private. `?type=commander`. |
| `GET /decks/:id` | [deck](../../spec/support/schemas/deck.json) | Yours, or anyone's public deck. `?include=rulings`. |
| `GET /users/:username/decks` | page of [deck_summary](../../spec/support/schemas/deck_summary.json) | Their public decks. Username isn't case-sensitive. |
| `GET /precon_decks` | page of [precon_deck_summary](../../spec/support/schemas/precon_deck_summary.json) | Commander precons, newest first. `?q=` name. |
| `GET /precon_decks/:id` | [deck](../../spec/support/schemas/deck.json) | Same shape as a user deck. `?include=rulings`. |
| `POST /cards/batch` | [card_batch](../../spec/support/schemas/card_batch.json) | Up to 200 `oracle_ids` **or** `card_uuids`. `?include=rulings`. |
| `GET /cards/search` | page of [card_summary](../../spec/support/schemas/card_summary.json) | `q` required. `?token=true` for tokens only. |
| `GET /tokens` | page of [card](../../spec/support/schemas/card.json) | Deduplicated token definitions. `?q=`, `?include=rulings`. |

Deck lists are most recently changed first, search puts exact and prefix name matches first, and tokens
are sorted by name. Another user's private deck, a collection that isn't a deck, and a non-Commander precon all return `404`, the same as a missing id.

## Auth

`POST /sessions` with email and password returns a token, shown only in that response. Send it on every
other request as `Authorization: Bearer mtg_...` and keep it in the OS keychain. Tokens last 90 days and
the window slides with each use. A missing, unknown, revoked or expired token gets `401 unauthorized`
with `WWW-Authenticate: Bearer`: drop the token and show the login screen. Tokens are revoked by
`DELETE /sessions`, from the web settings page (one or all), or by a password reset. Logins are throttled
to 10 per 15 minutes per IP and per email (`429 throttled`).

## Errors

Every error uses the [error](../../spec/support/schemas/error.json) envelope,
`{ "error": { "code": "...", "message": "..." } }`. Branch on `code`; `message` is for logs.

| Status | `code` | When |
| --- | --- | --- |
| 401 | `unauthorized` / `invalid_credentials` | Bad token / wrong email or password |
| 404 | `not_found` | Unknown or hidden record, or unknown `/api/v1` path |
| 422 | `parameter_missing` / `invalid_parameter` / `too_many_ids` | Bad parameters |
| 429 | `throttled` | Too many logins |
| 500 | `internal_error` | Unhandled exception (production only) |

## Pagination

List endpoints take `page` (default 1) and `per_page` (default 25, max 100); invalid values fall back to
the defaults. The response is a [page](../../spec/support/schemas/page.json): `data` plus
`meta: { page, per_page, total }`.

## Semantics the schemas can't capture

- **Strings, not numbers:** `power` and `toughness` (`*`, `1+*`), `loyalty` and `defense` (`X`), and
  `set.card_number` (`123a`). `null` when the face has none.
- **`mana_cost`** is brace notation: `{2}{W}{U/P}{X}`. `mana_value` is the whole card's, repeated on every
  face of a split or adventure card.
- **Faces:** one card object per printing, faces ordered by `side` (`a`, `b`, ...). Asking for a back
  face returns the front's object, so match cards on `oracle_id`. A meld result stands alone with face `b`.
- **Canonical printing:** a lookup by oracle id or name returns the newest printing with an image from a
  regular set, falling back to promos or imageless printings (`MagicCard::CANONICAL_PRINTING_ORDER`).
  `/tokens` returns one printing per distinct name, P/T, colors and text.
- **Images** are Scryfall CDN URLs and any of them can be `null`. Show a local fallback.
- **Decklist counting** (user decks): every row counts, so the client plays the deck as the deck builder
  shows it. An owned or needed row counts `quantity + foil_quantity + proxy_quantity + proxy_foil_quantity`;
  a staged row counts the four `staged_*` quantities. Rows of one printing on one board are merged, and
  rows that count 0 are left out. `cards[].quantity` sums to `deck.card_count`
  (`CollectionMagicCard#decklist_quantity`).
- **Precon boards:** mtgjson's `commander` and `mainBoard` become `commander` and `mainboard`. The
  sideboard is left out, and the precon's tokens go in `tokens` instead of on a board. User decks also
  return `sideboard`, and their `tokens` is always `[]`.
- **Caching:** deck and precon shows send an `ETag` and `Last-Modified`. Send the ETag back as
  `If-None-Match` to get `304` with no body when nothing changed. Prefer it to `If-Modified-Since`, which
  only has whole seconds.
- **Versioning:** `/health` returns `min_client_version`. Bump `Api::V1::HealthController::MIN_CLIENT_VERSION`
  when a change breaks older clients.
